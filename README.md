# Wiki Graph

Graph view for [Wikipedia](https://www.wikipedia.org/). This is based on [vs](https://github.com/anvaka/vs). Read more [on Reddit](https://www.reddit.com/r/dataisbeautiful/comments/10tj7cq/graph_view_for_wikipedia_articles_details_in_the/).
